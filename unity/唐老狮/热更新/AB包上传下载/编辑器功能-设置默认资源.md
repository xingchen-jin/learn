## 一、脚本干什么（一句话）

用户在 Project 窗口选中一批 AB 包，点菜单，把**无后缀的 AB 包**复制到 `Assets/StreamingAssets/`，同时用 `System.IO` 读出复制后文件的大小和 MD5，拼成对比文件 `ABCompareInfo.txt`。

一句话：**`Selection` 拿选中 → `AssetDatabase` 复制 → `System.IO` 统计 → `File.WriteAllText` 落盘 → `Refresh` 刷新。**

## 二、编辑器 API 逐个讲

### 1. `[MenuItem]` —— 菜单入口

```csharp
[MenuItem("AB包工具/移动AB包到StreamingAssets")]
public static void MoveABToStreamAsset()
```

| 规则 | 说明 |
|------|------|
| 只能加在 **`static`** 方法上 | 非静态 Unity 不识别 |
| 路径用 `/` 分隔 | 自动生成"AB包工具 → 移动AB包到StreamingAssets"菜单 |
| 脚本必须放 **`Assets/Editor/`** 下 | 否则打包时 `UnityEditor` 命名空间不存在，报错 |

> 这就是为什么这个类没继承 `MonoBehaviour`——**编辑器工具类不需要挂 GameObject，纯静态方法即可**。

### 2. `Selection` —— 拿到用户选中的资源

```csharp
Object[] selectedAssets = Selection.GetFiltered(
    typeof(UnityEngine.Object), SelectionMode.DeepAssets);
```

| 参数 | 作用 |
|------|------|
| `typeof(UnityEngine.Object)` | **类型过滤**：任何资源都继承自 `Object`，所以传它等于"不过滤类型" |
| `SelectionMode.DeepAssets` | **深度选择**：选中文件夹时，**递归包含里面所有子资源** |

**为什么选 `DeepAssets` 而不是 `TopLevel`**：用户通常会选中"`AB/PC`"整个文件夹，`TopLevel` 只会返回这个文件夹本身，`DeepAssets` 才会把文件夹里的 `lua`、`model` 等 AB 包都展开返回。

**其他 `SelectionMode` 值**：

| 值 | 含义 |
|----|------|
| `TopLevel` | 只返回顶层选中项（选文件夹不含里面） |
| `Assets` | 只返回 Project 窗口里的资源 |
| `Editable` | 只返回可编辑的（排除 dll 等） |

**空选中保护**：

```csharp
if (selectedAssets.Length == 0)
    return;
```

> 用户没选任何东西就点菜单时，直接退出，避免后面 `Substring` 越界。

### 3. `AssetDatabase.GetAssetPath` —— 拿资源路径

```csharp
string assetPath = AssetDatabase.GetAssetPath(asset);
// 返回如 "Assets/ArtRes/AB/PC/lua"
```

| 特点 | 说明 |
|------|------|
| 返回 **`Assets/` 开头的相对路径** | 不是磁盘绝对路径 |
| 只对 `Assets/` 下的资源有效 | 外部资源返回空字符串 |
| 与 `AssetDatabase.LoadAssetAtPath` 配对使用 | 一个拿路径，一个按路径加载 |

**为什么不用 `System.IO` 拼路径**：因为 `asset` 是 Unity 的 `Object`，它**只知道自己属于哪个 Asset**，不知道磁盘位置；必须通过 `AssetDatabase` 反查路径。

### 4. `AssetDatabase.CopyAsset` —— 复制资源

```csharp
string targetPath = "Assets/StreamingAssets/" + assetName;
AssetDatabase.CopyAsset(assetPath, targetPath);
```

| 规则 | 说明 |
|------|------|
| **两个路径都必须 `Assets/` 开头** | 不能用 `Application.streamingAssetsPath` 这种绝对路径 |
| **目标目录必须已存在** | `Assets/StreamingAssets` 不存在会复制失败（注释也提醒了） |
| **自动生成 `.meta` 文件** | Unity 立即知道这是新资源 |
| **自动处理导入** | 纹理、预制体等会被重新导入 |

**和 `File.Copy` 的本质区别**：

| | `File.Copy` | `AssetDatabase.CopyAsset` |
|--|-------------|---------------------------|
| 层面 | 操作系统磁盘层 | Unity 项目资源层 |
| Unity 感知 | ❌ 需要手动 `Refresh` | ✅ 立即感知，自动处理 meta |
| 路径格式 | 绝对路径 / 相对路径都行 | **必须 `Assets/` 开头** |
| 适用 | 日志、运行时文件 | 项目资源复制 |

### 5. `AssetDatabase.Refresh` —— 刷新编辑器

```csharp
AssetDatabase.Refresh();
```

**为什么需要它**：脚本里用 `File.WriteAllText` 直接把 `ABCompareInfo.txt` 写到了磁盘——这是**操作系统层面**的操作，Unity **不知道**有这个文件。`Refresh` 让 Unity 重新扫描 `Assets/` 目录，把新文件纳入资源数据库，Project 窗口才会立即显示。

> **规律**：只要用了 `System.IO` 写文件到 `Assets/` 下，后面就要 `Refresh`。

## 三、System.IO API 逐个讲

### 1. `Substring` + `LastIndexOf` —— 从路径里取文件名

```csharp
string assetName = assetPath.Substring(assetPath.LastIndexOf("/") + 1);
// "Assets/ArtRes/AB/PC/lua" → "lua"
```

| API | 作用 |
|-----|------|
| `LastIndexOf("/")` | 找**最后一个** `/` 的位置（`IndexOf` 是第一个） |
| `Substring(startIndex)` | 从 startIndex 截到末尾 |
| `LastIndexOf("/") + 1` | 跳过 `/` 本身，从下一个字符开始 |

**更规范的替代**：`Path.GetFileName(assetPath)`，一行搞定，但需要 `using System.IO;`。

### 2. 判断"是不是 AB 包"：`IndexOf(".")`

```csharp
if (assetName.IndexOf(".") != -1)
    continue;
```

| 含义 | 说明 |
|------|------|
| `IndexOf(".") != -1` | 文件名里**有点号** → 有后缀 → 不是 AB 包 |
| `-1` | 找不到，无点号 → 无后缀 → 是 AB 包 |

**注释里提到的更安全方式**：

```csharp
string ext = Path.GetExtension(assetPath);   // ".manifest" 或 ""
if (ext != "") continue;                     // 有后缀就跳过
```

**为什么更安全**：AB 包名理论上可以含点号（如 `"lua.v1"`），`IndexOf(".")` 会误判成有后缀；`Path.GetExtension` 只看**最后一个点之后**的部分，更准确。

### 3. `FileInfo` —— 读文件大小和完整路径

```csharp
FileInfo fileInfo = new FileInfo(Application.streamingAssetsPath + "/" + assetName);
fileInfo.Length;      // 字节数 long
fileInfo.FullName;    // 完整路径
```

| 要点 | 说明 |
|------|------|
| **构造时不读盘** | `new FileInfo(path)` 只是存了个路径，第一次访问属性才去读 |
| `.Length` | 文件字节数，`long` 类型 |
| `.FullName` | 完整路径，传给 `GetMD5` 用 |
| **文件必须已存在** | 访问 `Length` 时文件不在会抛 `FileNotFoundException` |

**为什么要在 `CopyAsset` 之后创建**：`CopyAsset` 是 Unity 资源层操作，执行完后磁盘上确实已经有文件了，所以此时 `new FileInfo(...)` 能读到正确的 `Length`。

### 4. `Application.streamingAssetsPath` —— 和 `AssetDatabase` 路径的关系

```csharp
FileInfo fileInfo = new FileInfo(Application.streamingAssetsPath + "/" + assetName);
```

**同一个目录，两种路径**：

| 写法 | 类型 | 用途 |
|------|------|------|
| `"Assets/StreamingAssets/" + assetName` | **Unity 相对路径** | 给 `AssetDatabase` 用 |
| `Application.streamingAssetsPath + "/" + assetName` | **磁盘绝对路径** | 给 `System.IO` / `FileInfo` 用 |

**两者指向同一个物理目录**，只是**给不同 API 用**。混用会报错：

- `AssetDatabase.CopyAsset` 传绝对路径 → 报 `Invalid AssetDatabase path`
- `FileInfo` 传 `Assets/` 开头相对路径 → 相对当前工作目录，大概率找不到

### 5. `File.WriteAllText` —— 写对比文件

```csharp
File.WriteAllText(Application.streamingAssetsPath + "/ABCompareInfo.txt", abCompareInfo);
```

| 特点             | 说明                            |
| -------------- | ----------------------------- |
| **覆盖写**        | 文件已存在则直接覆盖，不追加                |
| **文件不存在则创建**   | 目录必须已存在                       |
| 编码             | 默认 UTF-8 无 BOM                |
| 后面需要 `Refresh` | 因为 Unity 不知道 `System.IO` 写了文件 |

### 6. `Substring` 去尾换行

```csharp
abCompareInfo = abCompareInfo.Substring(0, abCompareInfo.Length - 1);
```

循环里每行末尾加了 `\n`，最后一行会多出一个空行 → `Substring(0, Length - 1)` 砍掉最后一个字符。

**⚠️ 隐患**：如果一个 AB 包都没选中（`abCompareInfo == ""`），`Length - 1 = -1`，`Substring` 抛 `ArgumentOutOfRangeException`。**实际项目应加保护**：

```csharp
if (abCompareInfo.Length > 0)
    abCompareInfo = abCompareInfo.Substring(0, abCompareInfo.Length - 1);
```

## 四、完整流程串起来

```
用户选中 AB 文件夹，点菜单
  │
  ├─ Selection.GetFiltered(Object, DeepAssets)
  │     → 拿到 [lua, model, ui, xxx.manifest, ...]
  │
  ├─ foreach 遍历
  │    ├─ AssetDatabase.GetAssetPath(asset)          // "Assets/ArtRes/AB/PC/lua"
  │    ├─ Substring + LastIndexOf("/")                // 取文件名 "lua"
  │    ├─ IndexOf(".") != -1 ? continue               // 有后缀 → 跳过 manifest
  │    ├─ AssetDatabase.CopyAsset(assetPath, "Assets/StreamingAssets/lua")
  │    │     → 复制到 StreamingAssets，生成 .meta，Unity 立即感知
  │    ├─ new FileInfo(Application.streamingAssetsPath + "/lua")
  │    │     → 读磁盘文件大小
  │    └─ abCompareInfo += "lua 1024 abc..." + "\n"
  │
  ├─ Substring(0, Length - 1)                         // 去尾换行
  ├─ File.WriteAllText(streamingAssetsPath + "/ABCompareInfo.txt", ...)
  │     → System.IO 写磁盘，Unity 不知道
  └─ AssetDatabase.Refresh()                          // 让 Unity 扫描到新文件
```

## 五、易错点汇总

| 类别 | 易错点 | 正确做法 |
|------|--------|---------|
| 编辑器 | `AssetDatabase.CopyAsset` 目标用绝对路径 | 必须 `Assets/StreamingAssets/xxx` 相对路径 |
| 编辑器 | `Assets/StreamingAssets` 不存在 | 提前 `Directory.CreateDirectory` 或要求手动创建 |
| 编辑器 | `File.WriteAllText` 后不 `Refresh` | Project 窗口看不到新文件，必须加 |
| 编辑器 | 脚本放非 `Editor` 目录 | 必须 `Assets/Editor/` 下，否则打包报错 |
| 编辑器 | `Selection.GetFiltered` 用 `TopLevel` | 选文件夹要递归，用 `DeepAssets` |
| 文件 | 用 `assetName.IndexOf(".")` 判断后缀 | 用 `Path.GetExtension` 更准（AB 名可含点） |
| 文件 | `FileInfo.Length` 在 `CopyAsset` 之前读 | 先复制再读，否则文件还不存在 |
| 文件 | 空选中时 `Substring(0, -1)` 越界 | 加 `if (Length > 0)` 保护 |
| 路径 | 混用 `Assets/` 相对路径和绝对路径 | 给 `AssetDatabase` 用相对，给 `System.IO` 用绝对 |
| 路径 | 试图往 `StreamingAssets` 写运行时文件 | 运行时写 `persistentDataPath`，`StreamingAssets` 移动端只读 |
