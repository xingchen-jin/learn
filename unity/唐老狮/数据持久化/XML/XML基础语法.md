## 一、创建 XML 文件

XML 文件本质上是**纯文本文件**，只是遵循特定的语法规则。

### 编辑工具选择

|类别|工具|特点|
|---|---|---|
|系统自带|记事本、写字板|零安装，随时可用|
|专用编辑器|XML Spy / XML Sphere|内置语法校验，报错直观|
|通用编辑器|**Sublime Text**（推荐）|功能强大，支持多语言编辑|

### 创建步骤

```
右键 → 新建 → 文本文档 → 修改后缀名为 .xml → 用编辑器打开编写
```

> ⚠️ 若系统未显示文件后缀名，需先在文件夹选项中开启「显示文件扩展名」。

## 二、注释写法

### 固定语法

```xml
<!-- 这是单行注释 -->

<!--
这是多行注释
可以跨越多行
不影响文件格式
-->
```

### 要点速记

- 以 `<!--` 开头，`-->` 结尾
- 支持单行和多行
- 注释内容不参与解析，仅辅助阅读

## 三、固定内容格式（文件声明）

> 🔴 **第一行必写，缺失则 XML 文件不完整，程序读取时会报错。**

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

### 字段解析

|字段|含义|说明|
|---|---|---|
|`version="1.0"`|XML 版本|目前默认使用 1.0|
|`encoding="UTF-8"`|编码格式|国际通用编码，防止中文乱码|

### 编码格式理解

```
字符 → 对应一个数字（二进制） → 不同编码 = 不同映射规则
```

- **编码格式**决定了字符在内存中对应的二进制表示
- 存储和读取必须使用**相同编码**，否则出现乱码
- **UTF-8** 是国际通用编码，兼容中英文等多种语言

> 💡 **类比理解**：就像老游戏汉化包编码不匹配导致乱码——存与读的编码必须一致。

## 四、基本语法（树形结构）

### 节点（元素）结构

```xml
<标签名>内容或子节点</标签名>
```

标签必须**成对出现**：开标签 `<name>` + 闭标签 `</name>`。

### 树形结构示例

以下示例完整展示了一个 XML 文件的结构：

```xml
<?xml version="1.0" encoding="UTF-8"?>

<player_info>
    <name>唐老师</name>
    <ATK>10</ATK>
    <item_list>
        <item>
            <ID>1</ID>
            <number>5</number>
        </item>
        <item>
            <ID>2</ID>
            <number>10</number>
        </item>
        <item>
            <ID>3</ID>
            <number>20</number>
        </item>
    </item_list>
</player_info>
```

### 对应的树形关系

```
player_info          ← 根节点
├── name             ← 叶子节点（存储文本数据）
├── ATK              ← 叶子节点
└── item_list        ← 中间节点
    ├── item         ← 可重复同名节点
    │   ├── ID
    │   └── number
    ├── item
    │   ├── ID
    │   └── number
    └── item
        ├── ID
        └── number
```

### 核心特征

- 🌳 **根节点唯一**：整个文档只有一个最外层节点
- 🍃 **叶子存数据**：标签之间包裹具体的文本内容
- 📂 **可嵌套子节点**：节点内部可包含其他节点
- 🔁 **同名可重复**：如 `<item>` 可出现多次，表示集合

## 五、基本规则（五大铁律）

|序号|规则|说明|示例|
|:-:|---|---|---|
|1|**必须有闭合标签**|每个开标签都必须有对应的闭标签|`<name>唐老师</name>`|
|2|**命名遵循变量规则**|不能数字开头，不能含特殊字符|✅ `playerInfo` ❌ `1player` ❌ `my-name!`|
|3|**大小写敏感**|`<Name>` 和 `<name>` 是不同标签|`<AGE>` ≠ `<age>`|
|4|**必须有且仅有一个根元素**|不能有多个并列的顶级节点|✅ 一个 `<root>` 包裹一切|
|5|**特殊符号用实体引用**|XML 保留字符需转义|见下表 ↓|

### 实体引用对照表

|符号|实体引用|含义|
|:-:|:-:|:-:|
|`<`|`&lt;`|小于号|
|`>`|`&gt;`|大于号|
|`&`|`&amp;`|与号|
|`"`|`&quot;`|双引号|
|`'`|`&apos;`|单引号|

> 示例：若 `<ATK>` 中要表达「攻击 < 防御」，应写作 `<ATK>攻击 &lt; 防御</ATK>`

## ❌ 常见错误对照

|错误写法|问题所在|正确写法|
|---|---|---|
|`<name>唐老师`|缺少闭合标签|`<name>唐老师</name>`|
|`<Player_info>...</player_info>`|大小写不一致|`<Player_info>...</Player_info>`|
|两个并列根节点|违反唯一根元素规则|外层再套一个根节点包裹|
|`<?xml ...?>` 写在第二行|声明必须是第一行|移到文件第一行|
|`<exp>A < B</exp>`|`<` 是保留字符|`<exp>A &lt; B</exp>`|
