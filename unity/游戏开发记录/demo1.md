## 人物移动不自然-出现滑动
人物的位移和旋转我是通过刚体组件进行的，的确能起到位移的·作用。但这也引起了一个问题，我刚体位移的速度依赖设置的速度，与移动动画没有什么联动。当速度设置不恰当时，会很不自然。会感觉到平移。或是再严格点，当人物抬脚到落脚过程中位移仍不断进行，一点不自然。

ai给出的解决方案有：

1，启用animator的RootMotion。也就是根运动

2，代码驱动位移+手动匹配动画速度

3，混合RootMotion与代码。（选择性的启用）

4，使用AnimationRigging做脚步IK锁定

## 8月10号 
- 重构FSM为两层状态机

```Csharp
csharp

namespace Game.Player
{
    public class PlayerContext : MyFSM.Blackboard
    {
        public Animator animator;
        public CharacterController controller;
        public PlayerInputData input;   // 定义的输入结构体
        // 两个状态机引用（方便互相查询）
        public MovementFSM movementFSM;
        public WeaponFSM weaponFSM;
        // 可被WeaponFSM修改的速度上限
        public float maxSpeed = 5f;
        public bool canRun = true;
    }
}
```

## 8月11号
完成状态机框架，以及基本移动状态，托起枪，瞄准的状态，FSM状态机框架基本成型，特点是状态与切换条件，输入的解耦，输入信息通过上下文（黑板）通信。状态内部不处理转换逻辑，由状态机维护转换条件的字典。判断。基础状态通过引用进行包装至封装类，而不是继承，相当于玩家组件与状态机进行了桥接。
