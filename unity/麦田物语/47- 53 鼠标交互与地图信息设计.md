## 实际做法：
先创建DataCollection中创建数据类，TileProperty。
成员：Vector2Int存坐标,bool类型boolTypeValue
,枚举GridType枚举网格类型;

创建SO文件存储地图；
存场景名和list的TileProperty

创建脚本GridMap，挂载在GridProperty的TileMap上


定义类前置的[ExecuteInEditMode]表示在编辑的模式下运行

CompressBounds()可以获取瓦片地图中实际存在的部分的范围

```csharp
using System.Collections;

using System.Collections.Generic;

using UnityEngine;

using UnityEngine.Tilemaps;

  

[ExecuteInEditMode]

public class GridMap : MonoBehaviour

{

    public MapData_SO mapData;

    public GridType gridType;

    public Tilemap currentTilemap;

    private void OnEnable()

    {

        if (!Application.IsPlaying(this))   //是否在运行时

        {

            currentTilemap = GetComponent<Tilemap>();

            if(mapData != null)

                mapData.tileProperties.Clear();

        }

    }

    private void OnDisable()

    {

        if (!Application.IsPlaying(this))

        {

            currentTilemap = GetComponent<Tilemap>();

  

            UpdateTileProperties();

  

            #if UNITY_EDITOR    

            if(mapData != null)

            {

                UnityEditor.EditorUtility.SetDirty(mapData);//标记为脏数据，保存时会保存数据

            }

            #endif

        }

    }

  

    private void UpdateTileProperties()

    {

        currentTilemap.CompressBounds();

        if(!Application.IsPlaying(this))

        {

            if(mapData != null)

            {

                var startPos = currentTilemap.cellBounds.min;//绘制范围的左下角

                var endPos = currentTilemap.cellBounds.max; //绘制范围的右上角

                for (int x = startPos.x; x < endPos.x; x++)

                {

                    for (int y = startPos.y; y < endPos.y; y++)

                    {

                        Vector3Int tilePosition = new Vector3Int(x, y, 0);

                        TileBase tile = currentTilemap.GetTile(tilePosition);

                        if (tile != null)

                        {

                            TileProperty tileProperty = new TileProperty()

                            {

                                tilePosition = new Vector2Int(x, y),

                                boolTypeValue = true,

                                gridType = this.gridType

                            };

                            mapData.tileProperties.Add(tileProperty);

                        }

                    }

                }

  

            }

        }

    }

}
```
这个脚本可以在编辑器窗口下运行，进行绘制时会将信息保存在SO，这量就可以批量自动的得到瓦片信息了。
‘’#if UNITY_EDITOR‘’可以让代码只在编辑器下运行

## 实现鼠标选中物品后场景点击事件流程
创建事件MouseClickEvent和ExecuteActionAfterAnimation
前者是使用物品时的鼠标点击事件，后者是鼠标点击触发完玩家动画后的实际事件。也就是前者负责动画的管理，后者则为实际数据与ui显示的管理。因为二者会存在一个先后顺序，比如丢弃物品动画完后实际丢弃。所以两个事件进行先后执行。

在鼠标管理器中玩家点击鼠标并可以使用物品时呼叫MouseClickEvent。再Player脚本中注册，执行动画后呼叫ExecuteActionAfterAnimation。

在GridMapManager注册ExecuteActionAfterAnimation
进行swtich判断item类型，执行相应逻辑。
**商品类（执行丢弃）：**  呼叫新定义的事件DropItemEven，在ItemManager和InventoryManager中分别注册，分别执行物品在场景的生成以及背包数量的对应处理

当丢弃最后一个物品时会出现一系列错误，这时候就要在对应模块中逐一解决，比如格子高亮取消，玩家动画取消等等。但这样写总是不方便的，如果可以更统一更面向对象的解决也许更好。

## 制作可以扔出的物品
我们主要使用阴影和图片造成视觉差达成物品扔出的效果
首先创建一个脚本ItemShdow，挂载在阴影子物体，存放阴影图和实际图；在start中根据实际图创造阴影图，存在意义貌似就这个。
然后创建一个ItemBounce脚本，挂载在父物体上，处理实际运动方法。
然后在ItemManager的丢弃事件中创造这个预制体。
移动方法
``` csharp
private void Bounce()

        {

            isGround = spriteTrans.position.y <= transform.position.y;//根据物体与父物体坐标比较，判断是否落地，阴影与父物体一致，实际图y值略高

  

            if(Vector3.Distance(spriteTrans.position, targetPos) > 0.2f)   //当阴影与目标位置距离大于0.1时，继续移动父物体

            {

                transform.position += (Vector3)direction  * distance * -gravity * Time.deltaTime;

            }

  

            if(!isGround)

            {

                spriteTrans.position += Vector3.up * gravity * Time.deltaTime;      //没落地继续下降

            }

            else

            {

                spriteTrans.position = transform.position;

                coll.enabled = true;

            }

  

            Debug.DrawLine(spriteTrans.position, transform.position,Color.red);

            Debug.Log(spriteTrans.position + "  " + transform.position);

        }
```
这个方法会检测物体是否落地以及物体是否到达目标点，
但物体落地的方法不是很好，因为容易超距离导致一直运动，也许可以用插值来做
