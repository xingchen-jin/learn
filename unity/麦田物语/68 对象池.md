使用unityEngine.Pool提供的ObjectPool`<T>`
一个基于栈的对象实例池，类型为 T，实现了 IObjectPool 接口。

使用此类创建可复用的对象实例池，以减少频繁实例化和销毁对象所带来的开销。

构造函数接受委托作为参数，以便您定义池在创建、取出、归还或销毁对象时的行为。您还可以指定池的默认容量、池可增长到的最大尺寸，以及归还对象时是否执行集合检查以捕获重复释放的错误。
使用 ObjectPool`<T0>`.Get从池中获取一个实例。如果池为空，则会使用传递给构造函数的创建方法来创建新实例。使用 ObjectPool`<T0>`.Release 将实例归还回池中。如果池已达到其最大尺寸，则会使用传递给构造函数的销毁方法来销毁该实例。

```csharp
    // 使用四个核心回调来创建对象池。
      pool = new ObjectPool<GameObject>(
        createFunc: CreateItem,          // 创建回调
        actionOnGet: OnGet,              // 获取回调
        actionOnRelease: OnRelease,      // 释放回调
        actionOnDestroy: OnDestroyItem,  // 销毁回调
        collectionCheck: true,           // 开启集合检查，帮助捕获重复释放的错误
        defaultCapacity: 10,             // 默认容量
        maxSize: 50                      // 最大容量
    );
```
可以通过Get和Release进行获取或释放，get不到函数自己会创建
