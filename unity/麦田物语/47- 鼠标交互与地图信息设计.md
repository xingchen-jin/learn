## 2，GridInformation

## 实际做法：
先创建DataCollection中创建数据类，TileProperty。
成员：Vector2Int存坐标,bool类型boolTypeValue
,枚举GridType枚举网格类型;

创建SO文件存储地图；
存场景名和list的TileProperty

创建脚本GridMap，挂载在GridProperty的TileMap上


定义类前置的[ExecuteInEditMode]表示在编辑的模式下运行

CompressBounds()可以获取瓦片地图中实际存在的部分的范围

```csharp
using System.Collections;

using System.Collections.Generic;

using UnityEngine;

using UnityEngine.Tilemaps;

  

[ExecuteInEditMode]

public class GridMap : MonoBehaviour

{

    public MapData_SO mapData;

    public GridType gridType;

    public Tilemap currentTilemap;

    private void OnEnable()

    {

        if (!Application.IsPlaying(this))   //是否在运行时

        {

            currentTilemap = GetComponent<Tilemap>();

            if(mapData != null)

                mapData.tileProperties.Clear();

        }

    }

    private void OnDisable()

    {

        if (!Application.IsPlaying(this))

        {

            currentTilemap = GetComponent<Tilemap>();

  

            UpdateTileProperties();

  

            #if UNITY_EDITOR    

            if(mapData != null)

            {

                UnityEditor.EditorUtility.SetDirty(mapData);//标记为脏数据，保存时会保存数据

            }

            #endif

        }

    }

  

    private void UpdateTileProperties()

    {

        currentTilemap.CompressBounds();

        if(!Application.IsPlaying(this))

        {

            if(mapData != null)

            {

                var startPos = currentTilemap.cellBounds.min;//绘制范围的左下角

                var endPos = currentTilemap.cellBounds.max; //绘制范围的右上角

                for (int x = startPos.x; x < endPos.x; x++)

                {

                    for (int y = startPos.y; y < endPos.y; y++)

                    {

                        Vector3Int tilePosition = new Vector3Int(x, y, 0);

                        TileBase tile = currentTilemap.GetTile(tilePosition);

                        if (tile != null)

                        {

                            TileProperty tileProperty = new TileProperty()

                            {

                                tilePosition = new Vector2Int(x, y),

                                boolTypeValue = true,

                                gridType = this.gridType

                            };

                            mapData.tileProperties.Add(tileProperty);

                        }

                    }

                }

  

            }

        }

    }

}
```
这个脚本可以在编辑器窗口下运行，进行绘制时会将信息保存在SO，这量就可以批量自动的得到瓦片信息了。
‘’#if UNITY_EDITOR‘’可以让代码只在编辑器下运行

## 生成地图数据
#### 创建地图信息管理器

```
[System.Serializable]

public class TileDetails

{

    public int gridX,gridY;

    public bool canDig,canDropItem,canPlaceFurniture,isNPCObstacle;

    public int daysSinceWatered = -1;

```

创建GridMap管理器，在里面定义public Dictionary<string, TileDetails> tileDetails= new Dictionary<string, TileDetails>();字典
并在游戏开始时根据MapData_SO列表生成/刷新字典内容


#### 控制鼠标可交互范围
在鼠标管理器中获取鼠标的世界坐标以及对应瓦片位置。
前者依靠unity的主相机获取，后者依靠Grid网格获取
函数分别为ScreenToWorldPoint和WorldToCell。
Grid的获取在场景加载后事件中。
由于游戏一开始就需要获取Grid，所以可以在Start中获取。
视频给出的解决方案是，把TransionManager的Start改成协程，
在里面呼叫场景切换后事件。
然后可以注意到场景加载的间隙鼠标管理器也会进行update，这时会丢失Grid导致报错，可以用一个bool变量进行控制
