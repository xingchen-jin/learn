# 常用设计模式
### 单例模式
单例模式可以被用在一个类上，它确保了两点： 
（1）始终只允许有一个该类的实例 
（2）对于该实例有一个全局的访问点
我们游戏中许多的“Manager”类（只有一个manager，且该manager提供许多常用功能）都需要具备这两点特征。
![](assets/Pasted%20image%2020260629122223.png)
在项目中我们可能会用到多个单例类，对于每个单例类都写上那么一段单例模式代码实在不是很优雅。 我们可以创建一个**通用的单例类**，并让每个真正用到的单例类**继承**自它就好了！


### 指令模式

指令模式就是“Ctrl+Z”的灵魂所在！这个设计模式将我们的每一个操作抽象成一个指令，并给每个指令一个“撤销”的操作。这样，我们只要记录之前完成过的指令就可以一步步往回撤销啦
```
public interface ICommand
{
	void Execute();
	void Undo();
}
public class ConcreteCommand : ICommand{
	public void Execute(){
		//执行指令
	}
	public void Undo(){
		//撤销指令
	}
}
```
