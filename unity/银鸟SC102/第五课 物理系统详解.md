
# 物理引擎概论
当两次FixedUpdate之间相隔的时间**小于固定步长**时，第二次FixedUpdate会被**跳过**。 在高帧率下，这种情况可能会引起一些卡顿或不协调；于是Unity会在每一渲染帧对物 理行为进行**插值**来在两次物理更新之间维持平滑过渡。
**Rigidbody中的Interpolation选项就定义了这个插值行为**

# 碰撞检测
### 离散碰撞检测Discrete Collision Detection
顾名思义，DCD会在一个个离散的时间点进行物理计算并更新物体的位置等信息
每一个物理帧中，DCD会做这么几件事： 
（1）获取物体上一帧的位置、速度等信息并根据此计算出新的位置与速度 
（2）对于这些新位置，DCD会检测是否与其他物体重叠 
（3）如果有重叠，则进入碰撞物理计算并得出最后的位置与速度

### Sweep-based CCD
Sweep-based CCD把一个物体的运动轨迹想象成一个“扫动的范围”，并使用该较大的扫动范围作为新的物理体积进行碰撞检测。

**依赖线速度，并不能处理角速度较大时物体的碰撞。且极其消耗性能。**

### Speculative CCD

这种方法会**根据上一帧的数据预测一个物体当前帧的位置与速度**。这种预测可以通过**扩大物体的物理体积**来实现。
具体是扩大物体的**AABB**（**坐标轴对齐包围盒**）。找出碰撞点的**法线**。

##### Ghost Collision幽灵碰撞
当地面是两个平面拼接而成，小球在地面往前行走会产生两个法线，c1是正常法线，脚下平面向上，c0为不应该存在的发现，碰撞点斜向上，从而造成被弹起的异常

# 关节组件
### 连接关节组件：Fixed Joint

除了基本的刚体与碰撞盒组件外，Unity还为我们提供了许多增加**刚体行为与互动的组件**，比如**连接关节**。 **Fixed Joint组件**允许我们把一个**刚体“粘”到另一个刚体上**，也允许它们在一定力之下**断裂**。

Connected Body：连接对象的刚体组件 
Break Force：断裂所需要的力
Break Torque：断裂所需要的扭矩

### 连接关节组件：Hinge Joint

Hinge Joint组件为刚体添加了“由**铰链连接**”的行为，比如常见的**门**就是这样。 
除了门，我们也可以用Hinge Joint实现**摆锤、锁链**等效果。

Connected Body：连接对象的刚体组件 
Axis：围绕的轴
Anchor：轴上的位置 
Break Force：断裂所需要的力
Break Torque：断裂所需要的扭矩

### 连接关节组件：Spring Joint

Spring Joint组件为刚体添加了“由弹簧连接”的行为，也就是说有一股力不断地尝试将两个刚体拉向同一个点。

几个重要属性：
Connected Body：连接对象的刚体组件 
Anchor：弹簧固定的位置
Spring：弹簧的强度
Damper：弹簧减速的快慢 
Break Force：断裂所需要的力
Break Torque：断裂所需要的扭矩

# 2D作用器

2D作用器（Effector2D）可以给2D物理物体增加一些更复杂的行为。它们必须搭配Collider2D组件使用。
2D作用器包括： 
AreaEffector2D：在一定区域内对所有物体施加一个力 
BuoyancyEffector2D：在一定区域内产生浮力
PlatformEffector2D：通常用来制作单向平台 
PointEffector2D：在一个点向四周的物体施加吸引力/斥力 
SurfaceEffector2D：让接触一个表面的物体沿着表面移动（传送带）

# 射线检测
### 盒状射线检测BoxCast
``public static RaycastHit2D BoxCast(Vector2 origin, Vector2 size, float angle, Vector2 direction, float distance, int layerMask)``

BoxCast函数以**origin**为起点生成一个长宽为**size**，**旋转角度**为angle的矩形方块，并将其向 **direction**方向投出**distance的距离**。接着BoxCast会返回接触到的物体信息。

Origin为角色碰撞盒的中心 
Direction为Vector2.Down 
Angle为0 
Size为角色碰撞盒的size（这样可以解决平台边缘的情况？） 
Distance为一个很小的值（这样可以大概解决斜坡的情况）
