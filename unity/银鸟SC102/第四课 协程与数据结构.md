# 枚举器接口 IEnumerator
枚举器接口提供了一种通用的遍历集合的方法。比如当我们使用foreach循环时其实就是使用了一个IEnumerator。
``` csharp
public interface IEnumrator
{
	bool MoveNext();
	object Current{get;}
	void Reset();
}
```
IEnumerator由三个成员组成，其中MoveNext()和Current是其核心。 大概的步骤不难想象： 
1. 我们拿到一个集合（array、list、etc.）
2. 获取一个该集合的枚举器 
3. 使用Current访问当前元素并用MoveNext()移至下一个元素，直 到遍历完成

# 可被枚举接口IEnumerable
和枚举器相关的接口还有一个：IEnumerable。它非常简单，仅仅是代表“可被枚举”这个特性：具体来说，继承自此接口的对 象必须拥有一个返回**IEnumerator**的名叫**GetEnumerator()
的方法。
```csharp
public interface Ienumerable
{
	IEnumerator GetEnumerator();
}
```
我们所熟知的C#自带的数据结构大多都是IEnumerable的，它们包括 Array、List、Dictionary、Stack、Queue等等。**
### 遍历
```csharp
IEnumerable sequence = new List { 1, 2, 3, 4, 5 };
IEnumerator enumerator = sequence.GetEnumerator();
while(enumerator.MoveNext())
{
	int current = enumerator.Current;
	print(current);
}
```
