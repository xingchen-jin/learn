# 枚举器接口 IEnumerator
枚举器接口提供了一种通用的遍历集合的方法。比如当我们使用foreach循环时其实就是使用了一个IEnumerator。
``` csharp
public interface IEnumrator
{
	bool MoveNext();
	object Current{get;}
	void Reset();
}
```
IEnumerator由三个成员组成，其中MoveNext()和Current是其核心。 大概的步骤不难想象： 
1. 我们拿到一个集合（array、list、etc.）
2. 获取一个该集合的枚举器 
3. 使用Current访问当前元素并用MoveNext()移至下一个元素，直 到遍历完成

# 可被枚举接口IEnumerable
和枚举器相关的接口还有一个：IEnumerable。它非常简单，仅仅是代表“可被枚举”这个特性：具体来说，继承自此接口的对 象必须拥有一个返回**IEnumerator**的名叫**GetEnumerator()
的方法。
```csharp
public interface Ienumerable
{
	IEnumerator GetEnumerator();
}
```
我们所熟知的C#自带的数据结构大多都是IEnumerable的，它们包括 Array、List、Dictionary、Stack、Queue等等。**
### 遍历
```csharp
IEnumerable sequence = new List { 1, 2, 3, 4, 5 };
IEnumerator enumerator = sequence.GetEnumerator();
while(enumerator.MoveNext())
{
	int current = enumerator.Current;
	print(current);
}
```
### Iterator和yield
当我们在一个返回**IEnumerable**的函数中使用**yield**关键字时，系统会帮我们**自动生成一个继承自IEnumerable的类**，并在该类中 实现我们所写的逻辑。（包括MoveNext()等方法）

这个自动生成的类比较复杂，不过它所做的事并不多：
1. 它会**记录当前迭代的状态**，包括本地变量的值与迭代器在集合中的位置。 这是通过内部的一个状态机完成的。
2. 它会把**yield return x**翻译成“将**Current设为x**，记录当前的状态，并暂停执 行”这一系列操作。

于是，我们可以大概整理出yield return具体的功能了
1. 将内部枚举器的Current设为一个值（或者说“提供枚举器的下一个值”）
2. “暂停函数的执行”，并且在下一次执行该函数时从yield return的位置开始（而非从头开始）

```csharp
var numbers = ProduceEvenNumbers(5);
Console.WriteLine("Caller: about to iterate.");
foreach (int i in numbers) { 
	  Console.WriteLine($"Caller: {i}"); 
}
	
IEnumerable ProduceEvenNumbers(int upto) { 
	Console.WriteLine("Iterator: start."); 
	for (int i = 0; i <= upto; i += 2) {
		 Console.WriteLine($"Iterator: about to yield {i}"); 
		 yield return i; 
		 Console.WriteLine($"Iterator: yielded {i}");
	}	 
	Console.WriteLine("Iterator: end.");
}

// Output: 
// Caller: about to iterate. 
// Iterator: start. 
// Iterator: about to yield 0 
// Caller: 0 
// Iterator: yielded 0 
// Iterator: about to yield 2 
// Caller: 2 
// Iterator: yielded 2 
// Iterator: about to yield 4 
// Caller: 4 
// Iterator: yielded 4 
// Iterator: end.
```
